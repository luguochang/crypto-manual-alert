# Product screenshots

Two evidence classes are stored here and must not be conflated.

- `signal-desk-workflow-desktop.png`: desktop Product result surface.
- `signal-desk-workflow-mobile.png`: Pixel 7 responsive Product result surface.
- `signal-desk-live-result.png`: desktop viewport from the 2026-07-29 live local
  OKX + Tavily + model + Aegra + HITL walkthrough.
- `signal-desk-live-result-mobile.png`: Pixel 7 viewport of that completed task.
- `signal-desk-live-artifact-mobile.png`: Pixel 7 viewport of its persisted report.

The `workflow-*` pair is generated by the deterministic Playwright Product test in
`frontend/tests/e2e-product/work-product.spec.ts`. It verifies UI states, gates,
responsive layout, accessibility, and secret-safe rendering, but not provider
connectivity.

The `live-*` frames prove one local real-provider execution on the capture date.
They do not prove hosted identity, production HA/DR/SLO, or production readiness.
